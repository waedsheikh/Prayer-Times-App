# 🕌 Prayer Times App

A clean and responsive web application that displays accurate daily Islamic prayer times based on the user's location or selected city using an external API.

---

## 🌟 Features

- 📍 Automatic / Manual Location: Fetches prayer times based on geographic coordinates or city selection.
- ⏰ Real-time Prayer Schedule: Displays Fajr, Sunrise, Dhuhr, Asr, Maghrib, and Isha times.
- 🎨 Responsive UI: Fully optimized for mobile, tablet, and desktop screens.
- ⚡ Live Updates: Automatically highlights the current or upcoming prayer time.

---

## 🛠️ Built With

- HTML5 & CSS3 
- JavaScript (ES6+) 
- API: [Aladhan API](https://aladhan.com/prayer-times-api)

---

### Prerequisites

You need a web browser
